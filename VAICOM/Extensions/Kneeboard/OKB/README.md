# OKB Folder Layout

This folder hosts the OpenKneeboard (OKB Out) web UI resources.

- `OKB.html` - main shell that links CSS and JS assets
- `css/OKB.css` - extracted OKB styles
- `js/okb-01-core.js` - core state/constants/preferences
- `js/okb-02-data-map.js` - data shaping + map payload helpers
- `js/okb-03-flightplan.js` - flight-plan and timeline logic
- `js/okb-04-samap.js` - SA map rendering and overlays
- `js/okb-05-bootstrap.js` - render loop, event wiring, bootstrap
- `assets/OKB-SamThreatRanges.json` - SAM threat ranges source data
- `docs/OKBHelpDoc.html` - OKB help documentation source
- `docs/OKB-SamThreatRanges-Reference.md` - SAM reference notes
- `OKB-OUT-PROPRIETARY-LICENSE.md` - OKB asset/license notice
