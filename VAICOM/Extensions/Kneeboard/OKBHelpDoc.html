FLT PLN Tab

Overview: Flight plan viewer for DTC and RouteTool sourced files.

Contains: Structured table views of selected file content, mission timing hints, route data, page views (Time/NAVLOG/COM/CMDS/MAP), and map interaction readouts.

Purpose: This tab is intended as the mission planning and in-flight quick-reference board for timing, communications, commands, and route/map awareness.

Workflow

  1. Load the mission route package
    • Open Files (☰) and choose the active FLT PLN source (DTC or RouteTool).
    • Confirm the header updates with the selected package and route context.
    • If the expected file is missing, recheck export location and refresh file list workflow.
  2. Validate session and mission context
    • Open Session (ℹ) and verify aircraft, theatre, mission title, and current mission state.
    • Confirm route package aligns with the current sortie (avoid stale file from prior mission).
    • Close Session and return to FLT PLN for execution setup.
  3. Build your timing plan (TIME page)
    • Set/verify TOT as mission anchor timing.
    • Use mission-time readout to determine ahead/behind status against route progression.
    • Apply recommended speed schedule adjustments where needed to recover timing drift.
    • Mark ATA checkpoints as you progress through the mission.
  4. Cross-check route geometry and nav sequence (NAVLOG page)
    • Validate waypoint order, leg continuity, and key route values before push.
    • Use table/cell controls to inspect and adjust supported parameters.
    • Use NAVLOG as primary reference during enroute checks and reattacks.
  5. Configure support systems (COM / STORES / CMDS pages)
    • COM: Confirm frequencies/channels match current tasking and expected comm plan.
    • STORES: Validate payload, station assignment, and any mission-critical store constraints.
    • CMDS: Confirm loaded countermeasure programs and expected timing/sequences from DTC data.
  6. Maintain tactical picture (MAP page)
    • Toggle BG ON/OFF based on readability and mission need.
    • Use zoom/pan to inspect route legs, target area geometry, and divert options.
    • Use selection readouts for asset context and BRA/B-E style awareness where available.
    • Keep D-LINK ON when coalition datalink overlays are required.
  7. Execute in-mission update loop
    • Cycle pages as needed: TIME (timing), NAVLOG (route), COM (radios), CMDS/STORES (systems), MAP (SA).
    • Re-check timing after major events (takeoff, push, IP, target actions, egress, divert).
    • Use debug views only when troubleshooting data mismatches (raw JSON / server messages).
  8. Postflight capture and review
    • Use postflight controls/pages to record mission completion state and timing results.
    • Capture deviations between planned and actual timeline for follow-up tuning.
    • Retain the route package for debrief reference or refinement in next sortie.

Page Selection Modes

PAGE SELECTION

Figure 1. FLT PLN Page Selection and Postflight.
  • Mission-time and timing-centric readout panel. Can be clicked to mark current time and update mission clock context.
  • TOT can be edited to provide updated timing information and recommended speed schedule.
  • Used to mark ATAs at route checkpoints against mission clock context.
  • Supports quick verification of ahead and behind timings at route checkpoints.
  • Buttons for page navigation, DTC Route selection and postflight actions. See below for related information and usage.

NAVLOG

Figure 2. FLT PLN NAVLOG and waypoint management.
  • Primary navigation log view for route legs and waypoint sequencing.
  • Focuses on route progression, leg continuity, and planning data readability.
  • In cell controls allow adjustment of waypoint parameters. Clicking on cell headers change data units if applicable.
  • Useful for cockpit cross-check against aircraft systems and required TOT, ATA and ETAs.

COM

  • Communications reference page for channels/frequencies/related comm data when present in the mission or loaded via a DTC.
  • Intended for rapid radio setup and in-flight comms validation.
  • Pairs well with ATC/AWACS/JTAC workflow tabs for live operations.

STORES

  • Stores reference page for munitions, fuel, and other external stores when loaded on the jet.
  • Updated dynamically and allows rapidin-flight validation.
  • Ideal for confirming stores station position, hung ordnance, and other critical information.

CMDS

  • DTC generated countermeasures program information.
  • Includes details on deployment sequences and timing.
  • This is data passed via DTC, does not reflect changes made by the pilot using the cockpit controls.

MAP

  • SA map visualization page with overlays and contextual annotations.
  • Supports mission route geometry review, selected asset context, data and own ship position information. Also provides B/E and BRA-style readouts when assets are bugged.
  • Support own coalition Datalink assets (D-LINK selected on) that are updated in real time.

MAP Controls and Readouts

  • BG ON/OFF: Background map layer toggle.
  • Zoom/Pan controls: Used to inspect route sections and overlay details.
  • Selection readout: Displays selected element information when available.
  • Status line: Shows map/background availability state for current theatre/data.
  • Overlay content: May include route lines, destination points, airfield overlays, and tactical context markers.

Data Sources and Notes

  • DTC files: Loaded from Saved Games DTC export paths when available.
  • RouteTool files: Parsed from RouteTool preset output where supported.
  • Fallback behavior: If structured rendering is unavailable, a plain formatted data view is shown.
  • Debug support: Use global debug toggles (raw JSON/server messages) for troubleshooting content flow.

EFB Tab

Overview: Electronic Flight Bag workspace for chart viewing with a floating icon rail workflow and pinned favorites list.

Contains: Auto/manual airport selection, chart list drawer, global pinned chart drawer, local-file chart rendering, and viewport pan/zoom controls.

Left Rail Controls

  • Auto (A): Resolves/selects airport from current mission context, then opens the chart list for that airport.
  • Airport (🗼): Opens airport list drawer first; selecting an airport opens its chart list.
  • Pinned (📌): Opens pinned drawer (favorites) showing only charts explicitly pinned from chart rows.

Drawer Lists and Pinning

  • Chart list rows: Each chart row has a line pin icon. Toggle to pin/unpin that chart.
  • Pinned drawer behavior: Shows pinned charts from any airport as a global favorites list.
  • Pinned row format: Rows display AIRPORT · CHART NAME for clarity across multiple fields.
  • Unpin paths: You can unpin from either the airport chart list or from the pinned drawer itself.
  • Selecting pinned charts: Choosing a pinned row switches to that chart's airport and loads the selected chart.

Right Rail and Viewport Controls

  • Zoom Out (−): Decreases chart zoom.
  • Recenter (⟳): Resets zoom and pan to default centered view.
  • Zoom In (+): Increases chart zoom.
  • Pan/drag: Click-drag in chart viewport to move the chart image.

Night Mode and Chart Sources

  • Local folder charts: Night mode darkens chart brightness/contrast without hue swapping, so blue water and brown/orange terrain remain correct.
  • Navigraph charts: Dedicated provider-rendered night chart styling is expected when Navigraph chart mode is enabled.
